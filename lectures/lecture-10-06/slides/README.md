# Visitor Pattern lecture slides

- `lambda1_vp.tex`: editable LaTeX Beamer source (25 slides).
- `lambda1_vp.pdf`: compiled slides for presenting.

The deck explains Visitor roles, dispatch, traversal, and extension tradeoffs
before covering the interpreter in `../lambda1_vp.py`.

Run `make` to rebuild with a LaTeX installation containing Beamer, listings,
lmodern, and booktabs. Build intermediates go in `.build/`.

The existing PPTX files and `lambda1_vp-notes.md` belong to the earlier deck.
Their slide numbering does not apply to this Beamer revision.
